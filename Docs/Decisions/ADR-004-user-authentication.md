## Reasoning

Explain the reasoning in 4–8 sentences. This is the most important section.

you lose by making this choice, and any conditions that would cause you to
revisit the decision.

## Security implications

decision mean for the security model? What attack does it defend against, or
what attack surface does it open? If this decision has no security implications,
write "None."

## Consequences
